# Антиплагиат: Система анализа студенческих работ

Система предназначена для хранения работ, присланных студентами, и автоматического анализа на признаки плагиата. Реализована в виде микросервисной архитектуры с централизованным API Gateway.

## Архитектура

Система состоит из трёх микросервисов:

1. **`gateway-service` (порт 8080)**
    - Единая точка входа для клиентов.
    - Маршрутизирует запросы к другим сервисам.
    - Агрегирует отчёты и облака слов.

2. **`file-storage-service` (порт 8081)**
    - Хранит метаданные и содержимое работ студентов.
    - Генерирует SHA-256 хеш содержимого (без учёта пробелов и регистра).
    - Предоставляет внутренний API для поиска работ по хешу.

3. **`analysis-service` (порт 8082)**
    - Выполняет асинхронный анализ на плагиат.
    - Определяет плагиат как наличие более ранней работы с тем же хешем.
    - Генерирует облако слов через [QuickChart Word Cloud API](https://quickchart.io/documentation/word-cloud-api/).
    - Сохраняет результат в локальной БД.
